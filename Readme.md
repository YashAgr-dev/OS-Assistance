# 🤖 OS Assistant

A powerful **Python-based Voice Controlled OS Assistant** that helps automate Windows tasks using voice commands and keyboard input. It can open applications, control media, manage files, monitor the system, perform network operations, assist developers, and much more.

## 🛠️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/OS-Assistant.git
```

Move into the project

```bash
cd OS-Assistant
```

Install all dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run

```bash
python main.py
```
